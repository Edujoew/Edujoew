### 🏛️ [University Resource & Equipment Booking System](https://github.com/Edujoew/University-Resource-Booking-System-URBS)

> **A centralized platform for students and staff to reserve university assets, featuring integrated mobile payments.**

* 🛠️ **Backend & Logic:** Built with **Django** and **Python**, using **MariaDB** for robust data persistence.
* 💳 **Payment Integration:** Integrated **Safaricom Daraja API** to automate payment processing for resource booking fees.
* 📊 **Database Management:** Utilizes **SQLite** for rapid development and **MariaDB** for production-scale reliability.
* 🔐 **Key Features:** User authentication, real-time availability checking, and automated M-Pesa STK Push notifications.
